# Nonso’s Bakery Website  

## 📌 Project Overview  
Nonso’s Bakery is an artisanal bakery based in Johannesburg, South Africa. This website serves as a digital storefront to showcase products, share the bakery’s story, provide contact details, and engage customers with a visually appealing, responsive design.  

---

## 🎯 Goals & Objectives  
- Display product categories with images and descriptions.  
- Provide contact information and opening hours.  
- Share bakery news and promotions.  
- Create a visually appealing, user-friendly interface.  
- Ensure responsive design across devices.  
- Include **inline comments in HTML and CSS** to explain code clearly.  

---

## 🛠️ Features  
- **Homepage:** Banner image, introduction, product highlights.  
- **About Page:** Bakery story and mission.  
- **Gallery:** Grid layout of breads, cakes, and pastries.  
- **Contact Page:** Phone, email, address, and opening hours.  
- **Sitemap:** Organized links for accessibility and SEO.  
- **Styling:** Gradient backgrounds, box shadows, rounded corners, hover effects, transitions, animations, and responsive design.  
- **Documentation:** Inline comments in all HTML and CSS files, changelog.txt, and README.md.  

---

## 🎨 Design Aesthetic  
- **Color Scheme:** Warm tones (cream, brown, gold, orange).  
- **Typography:** Clear, consistent, and readable fonts.  
- **Layout:** Grid-based gallery, balanced sections, cohesive navigation.  
- **Decorative Elements:** Gradients, shadows, subtle animations.

## ⚙️ Technical Requirements  
- **HTML5 semantic tags** (`header`, `nav`, `main`, `section`, `footer`).  
- **CSS styling** with gradients, hover effects, transitions, animations, and responsive design.  
- **Inline comments** in HTML and CSS explaining code sections.  
- **Responsive layout** using media queries for mobile, tablet, and desktop.  
- **Cross-browser compatibility** tested on modern browsers.
